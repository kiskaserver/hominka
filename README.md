# Chat Overlay — чат поверх гри, невидимий для OBS

Прозорий оверлей, який показує сторінку твого чату (`/overlay/chat`) **поверх
будь-якої гри**, але **Windows приховує це вікно від захоплення екрана** — тобто
OBS (Display / Window / Game Capture) його **не бачить**. Глядачі бачать чат
один раз (той, що ти накладаєш в OBS), а ти читаєш його окремо на своєму екрані.

> Один монітор — більше не проблема: бачиш чат і відповідаєш людям прямо в грі.

## Запуск (найпростіше)

Двічі клікни **`run.bat`**. Перший раз він сам створить віртуальне середовище і
поставить залежності (~хвилину), далі — запускатиметься миттєво, без вікна
консолі.

## Запуск вручну

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python chat_overlay.py
```

Свій URL чату (якщо домен інший) можна передати аргументом:

```bat
python chat_overlay.py https://stream.svitix.com/overlay/chat?lang=uk
```

За замовчуванням URL заданий у `chat_overlay.py` (`CHAT_URL`).

## Як користуватись

| Дія | Як |
| --- | --- |
| Перетягнути | тягни за **верхню панель** |
| Змінити розмір | тягни за **куточок унизу праворуч** (або край) |
| Прозорість | **повзунок** на панелі |
| Клік-крізь (миша йде в гру) | кнопка **🔓/🔒** або **Ctrl+Alt+Space** |
| Закрити | **✕** |

Розмір, позиція і прозорість запам'ятовуються у `config.json` поруч.

**Клік-крізь (Lock 🔒):** коли увімкнено, вікно перестає ловити мишу — кліки
проходять у гру, а чат просто висить зверху. Щоб вимкнути назад (миша вже
проходить крізь, кнопку не натиснути), тисни **Ctrl+Alt+Space**.

## Вимоги

- **Windows 10 версії 2004 (build 19041) або новіша / Windows 11** — саме там
  працює приховування від захоплення (`WDA_EXCLUDEFROMCAPTURE`). На старіших
  Windows вікно працюватиме, але OBS зможе його побачити (у консолі буде
  попередження).
- Python 3.9+.

## Перевірка, що OBS не бачить оверлей

1. Запусти оверлей, признач йому місце поверх гри.
2. В OBS додай **Display Capture** (Захоплення екрана) або **Game Capture**.
3. Оверлей у прев'ю OBS **не з'явиться**, а на твоєму екрані буде видимий. ✔

> Якщо все ж видно в OBS — переконайся, що використовуєш Display/Window/Game
> Capture (а не, наприклад, захоплення другого монітора іншим способом), і що
> Windows оновлена до 2004+.
